10. RTL DOES NOT MEAN RIGHT-EDGE LAYOUT
==================================================
CRITICAL RULE: Arabic RTL does NOT mean the entire page should be physically pushed to the right. The page must be visually centered.
Use a consistent centered container:
width: 100%; max-width: 1200px; margin-inline: auto; padding-inline: 24px;
(Up to 1280px for wider sections).

==================================================
11. LAYOUT ROOT-CAUSE RULE
==================================================
When something looks misaligned, DO NOT patch it with random CSS (like arbitrary translateX or negative margins). Fix the root cause (Container width, Max-width, Margins, RTL direction, etc.).
